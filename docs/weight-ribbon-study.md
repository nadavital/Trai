# Weight ribbon study

Debug-only SwiftUI study: launch with `--ribbon-study`; add `--ribbon-dark` for dark appearance.

A coral ribbon folded into a soft W provides a fixed visual identity for weight. Four shaded path faces imply depth without spheres, progress fills, or a judgement about the latest measurement. Header, hero, and dashboard sizes use the same geometry. Sample log sheet edits local state only; it never writes HealthKit or app models.

The study is deliberately outside production navigation. Review the native captures before deciding whether this mark deserves integration. Full Dynamic Type and VoiceOver review remains open.
